# Trigonometric Identities Reference

Essential trigonometric rules, identities, and transformation formulas for Calculus 1 problems.

---

## 📐 Fundamental Identities

* **Pythagorean Identity:** $\sin^2 x + \cos^2 x = 1$
* **Tangent definition:** $\tan x = \frac{\sin x}{\cos x}$

---

## 🔄 Double-Angle & Half-Angle Formulas

### Double-Angle
$$\sin(2x) = 2\sin x \cos x$$
$$\cos(2x) = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$

### Power Reduction (Linearization)
$$\sin^2 x = \frac{1 - \cos(2x)}{2}, \quad \cos^2 x = \frac{1 + \cos(2x)}{2}$$

---

## ⚡ Universal Parametric Substitution ($t = \tan(x/2)$)

Used for trigonometric integrals $\int R(\sin x, \cos x) \, dx$:

$$\sin x = \frac{2t}{1 + t^2}, \quad \cos x = \frac{1 - t^2}{1 + t^2}, \quad dx = \frac{2}{1 + t^2} \, dt$$
