# Algebraic Tricks & Manipulation Techniques

Operational shortcuts commonly used to break down limits, integrals, and algebraic expressions.

---

## 🛠️ Common Manipulations

### 1. Conjugate Rationalization
Used to eliminate square roots in limits ($0/0$ or $\infty - \infty$):
$$\sqrt{a} - \sqrt{b} = \frac{(\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b})}{\sqrt{a} + \sqrt{b}} = \frac{a - b}{\sqrt{a} + \sqrt{b}}$$

### 2. Strategic Addition and Subtraction ($+1 / -1$)
Used to split rational functions for integration or limit evaluation:
$$\frac{x}{x + 1} = \frac{x + 1 - 1}{x + 1} = 1 - \frac{1}{x + 1}$$

### 3. Completing the Square
Used to set up quadratic polynomials for standard integrals like $\arctan$ or $\arcsin$:
$$ax^2 + bx + c = a \left( x + \frac{b}{2a} \right)^2 + \left( c - \frac{b^2}{4a} \right)$$
