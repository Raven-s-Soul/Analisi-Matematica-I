# 🧰 09. Useful Algebraic Methods & Extra Tools

This directory contains reference guides for essential algebraic techniques, polynomial manipulations, and trigonometric rules. These methods serve as prerequisites and problem-solving shortcuts throughout Calculus 1.

---

## 📄 Available Guides

* [Synthetic Division (Ruffini's Rule)](./ruffini-synthetic-division.md) — Step-by-step polynomial factorization and root finding.
* [Trigonometric Identities](./trigonometric-identities.md) — Fundamental identities, double/half-angle formulas, and $t = \tan(x/2)$ substitutions.
* [Algebraic Tricks & Manipulations](./algebraic-tricks.md) — Rationalization techniques, $+1/-1$ strategic splits, and completing the square.
