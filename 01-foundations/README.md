# 01. Foundations & Preliminaries

This directory covers the foundational mathematical structures, set theory concepts, and real number properties required for Calculus 1.

---

## 📌 Key Topics

### 1. Set Theory & Mathematical Logic
* **Logic Symbols:** Quantifiers ($\forall, \exists$), implications ($\implies, \iff$).
* **Set Operations:** Union ($\cup$), intersection ($\cap$), difference ($\setminus$), and complement.

### 2. The Real Number System ($\mathbb{R}$)
* **Number Sets:** $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$.
* **Completeness Axiom:** Every non-empty subset of $\mathbb{R}$ bounded above has a least upper bound (supremum) in $\mathbb{R}$.

### 3. Bounds & Extremums
* **Supremum ($\sup A$):** The smallest upper bound.
* **Infimum ($\inf A$):** The greatest lower bound.
* **Maximum & Minimum:** Extrema that belong directly to the set $A$.

### 4. Mathematical Induction
To prove $P(n)$ is true $\forall n \ge n_0$:
1. **Base Step:** Prove $P(n_0)$ is true.
2. **Inductive Step:** Assume $P(k)$ is true (Inductive Hypothesis) and prove $P(k+1)$ is true.

### 5. Properties of Functions
* **Injective (One-to-One):** $f(x_1) = f(x_2) \implies x_1 = x_2$.
* **Surjective (Onto):** $\forall y \in Y, \exists x \in X : f(x) = y$.
* **Bijective:** Both injective and surjective (invertible).
